# Protocol 5 development wallet

Recipient-key payments, exact lost-return recovery, authenticated H+1 state,
private selected-output capsules and one-attempt delivery now compose in one finite
trusted-host wallet. See [behavior, local use and limits](../../docs/PROTOCOL5_WALLET_CONTINUITY.md),
[component identities](COMPONENT_MANIFEST.json) and [dependency inventory](DEPENDENCY_RECEIPT.json).

The wallet uses actual Halo2 proofs on a local four-validator development network.
It supplies no production custody, automatic encrypted note discovery, anonymity,
metadata privacy, independent audit, public release or real-funds safety.
