## Format contract
Add an explicit backup envelope version 3 in p4_custody_compressed.py. It consumes the unchanged version-2 canonical typed row stream, including its original capture timestamp. The decoded stream, manifest, snapshot_id, seven journal tables, original transaction bytes, saved receipt bytes and historical auditor remain exactly version 2. The private recovery archive remains version 2. Version 3 is an encrypted transport representation only.

Each at-most-1-MiB plaintext chunk is independently encoded with standard-library zlib at a fixed writer level. Use raw fallback whenever the compressed representation is not strictly smaller. Define a canonical fixed header identifying schema/format, existing fixed Scrypt KDF, AES-256-GCM, fresh salt and nonce prefix, chunk size and the exact codec contract. No externally selected compression or KDF parameters.

A data frame carries codec, original plaintext length and ciphertext length. Authentication binds magic, exact header, frame kind, position, codec, plaintext length and encoded length before decoding. The final authenticated manifest commits to the exact original uncompressed stream and original row/BLOB counts. Nonfinal decoded chunks must be exactly 1 MiB. Bound original length and encoded length before reading/decryption, require raw length equality or strictly smaller zlib encoding, cap decompression output at expected length plus one, and reject incomplete zlib streams, unused bytes, concatenated streams, dictionaries and trailing files. Frame count and total uncompressed bytes remain the unchanged v2 limits. Derive a new physical envelope bound only from unchanged logical limits plus fixed new framing overhead.
