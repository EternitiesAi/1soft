# 1soft — cryptocurrency identity and scope

Owner decision recorded September 25, 2026: **1soft is the cryptocurrency name**.
The dedicated repository remains `xnuonux/1soft` and the public domain is `1soft.org`.
This engineering lane is the native cryptocurrency: monetary execution, node
storage, signing, network verification and operator tooling. Resident, Luna and
Psyche development are separate lanes and were not changed in this checkpoint.

The native application's advertised name is now `1soft-native-dev`. Existing
signature domains, account addresses, chain IDs, genesis hashes, native monetary
rules and transaction formats are not renamed or rewritten. A project name does
not authorize migration of anyone's signed history. The tickers, denominations,
public genesis allocations, issuance and reserve/issuer model remain undecided.
Existing `DEV` fixtures remain unbacked, valueless development units.

Compatibility with other agents is an interface objective, not an assertion of
live integration. No new identity credential or Resident work is included here.
The name is an owner's product choice, not a trademark-clearance conclusion.
