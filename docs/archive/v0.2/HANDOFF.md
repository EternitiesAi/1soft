## Exact next engineering boundary

Do not announce a blockchain from this SQLite model. Choose and run a supported consensus framework, with a revision/SDK/compiler lock that is actually buildable in the environment. A first acceptable chain milestone is communicating validator processes committing and verifying native transfers on a fresh genesis, with logs, node identities and reproducible commands. Preserve this reference model as an oracle for application behavior or port its exact semantics with cross-language vectors.

Before public testnet, extend account creation and key recovery, finish monetary/security economics and resource rules, integrate common authority accounting, and test partitions/restarts/upgrades. Do not use the known demo/test keys. Do not silently choose a premine from the 100 DEV fixture.

The Python journal has trusted callers and no real adapter authentication. Build a protected signing/consent boundary and provider evidence verifier before letting an agent invoke it. Cross-route shared budgets, native-to-journal atomicity, and exception debt resolution remain incomplete. Card-network exceptions mean local spending controls cannot be advertised as absolute limits on every external liability.

Preserve component-inspection scope and source blob identifiers. Do not claim upstream nodes/tests were executed. Retain executed/unexecuted distinctions. A matching local state hash is not consensus, an accounting credit is not reserve backing, a card rendering is not an issued card, and a network integration name is not a working integration.
